# Benchtop

[![CI](https://github.com/LauKil/benchtop/actions/workflows/ci.yml/badge.svg)](https://github.com/LauKil/benchtop/actions/workflows/ci.yml)

CLI tools to convert instrument files to better formats.

## Usage

```bash
benchtop ingest <file>
```

## Development

```bash
uv sync --all-groups
uv run pytest
```
